**Stock Sentiment Web-app**

This is a stock sentiment analyzer website using a neural network.

**Guide**

User visits webpage, inputs a stock ticker, and receives a prediction. 
The user can also pin stocks to a "watchlist" page.

**Implementation**

Frontend
 - ReactJS
 - HTML
 - CSS
   
Backend
 - Python
   
Datasets/packages
- huggingface
- ALPACA API
  
APIs
 - FastAPI
